modern Swift and explained step by step. Each entry links to a lesson file with
the full walkthrough; the corresponding solution also lives in `swift/<id>-*.swift`.

Pick-up point: this file always shows what's done and what's next, so each daily
run continues the sequence instead of repeating a problem.
