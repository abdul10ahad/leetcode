# NeetCode String Problems — Daily Learning Journal

A daily walkthrough of classic **string-pattern** LeetCode/NeetCode problems,
solved in Swift with modern APIs, explained step by step.

Each day adds one file: `dayNN-problem-slug.swift`. Every file contains:

1. The problem statement + link
2. The underlying **pattern** (the reusable technique, not just the problem)
3. A step-by-step walkthrough with a worked example trace
4. An idiomatic, modern-Swift solution
5. Time/space complexity
