**How this is used:** each scheduled run reads this table, picks the first
`⬜ Todo` row, walks through the problem step by step in chat with a modern
Swift solution, adds/updates the corresponding file in `swift/`, then flips
the row to `✅ Done` with today's date. This keeps daily sessions from
repeating a problem even though each session starts with no memory of the
previous one.
