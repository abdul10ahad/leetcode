problems. Each entry uses modern Swift APIs and walks through the pattern
step by step so the series builds into a full string-problem playbook.

Run once per day. Pick the next problem from the queue below, write a
lesson file `day-XX-<problem-number>-<slug>.md`, then move it from
"Queue" to "Completed" in this table.
