# NeetCode Strings — Daily Swift Study Log

A personal, daily walkthrough of NeetCode's "Strings" problem set, solved in
Swift with modern language APIs (`Character` properties, `String.Index`,
`Set`, functional `Sequence` methods, etc.). Each day covers exactly one
problem: a fresh solution + a step-by-step explanation, delivered in chat.

This log just tracks *progress* so the next run knows where to pick up —
it's separate from the main `swift/` solutions folder in this repo (which
holds one canonical community solution per LeetCode problem).
