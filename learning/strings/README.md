# NeetCode String Patterns — Daily Swift Curriculum

A personal, everyday walkthrough of the string-heavy problems from this repo,
solved in idiomatic modern Swift (`reduce(into:)`, `Dictionary` default
subscripts, `enumerated()`, `zip`, `StringProtocol` slicing, etc.) with a
step-by-step explanation of the flow for each one.

Each entry links to `NN-slug.md` in this folder, which contains:
- the pattern being taught
- a modern-Swift solution
- a step-by-step dry run
- time/space complexity
