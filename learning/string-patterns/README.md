# NeetCode String Patterns — Daily Swift Lessons

A personal, daily walkthrough of NeetCode-style **string** problems, solved in
Swift using modern language APIs, with a step-by-step explanation of the
underlying pattern each time.

This lives outside the per-language solution folders (`swift/`, `python/`,
etc.) on purpose — those already hold the repo's community-contributed
accepted solutions. This folder is a teaching log: one lesson per day, in the
order that best builds intuition for recurring string patterns, not
necessarily LeetCode problem-number order.

## How this works

Each day gets one markdown lesson: `NN-<leetcode-id>-<slug>.md`, where `NN` is
the day/sequence number. Every lesson covers:

1. The problem statement in brief
2. The **pattern** it teaches
3. A step-by-step reasoning flow (how you'd arrive at the solution)
4. A modern-Swift solution
5. A manual trace/dry-run through an example
6. Time/space complexity
