# NeetCode Strings — Swift Learning Log

A daily walkthrough of NeetCode's classic **string** problems, solved in Swift
using modern language APIs, with a step-by-step explanation for each one.

This lives alongside (not inside) the repo's community `swift/` solutions
folder so it doesn't collide with existing contributions — think of it as a
personal curriculum with its own notes.

Each entry gets:
- A `.swift` file: problem statement, step-by-step approach, annotated
  solution, complexity analysis, and a short "modern Swift APIs used" note.
- A checkbox below, ticked off the day it's covered.
