## How the daily run works
- Each day, find the first `⬜` row above, teach that problem (Swift, modern
  APIs, step-by-step reasoning) in chat, then mark it `✅ <date>` here and
  commit.
- Once all 12 are done, loop back and revisit with a variant/follow-up
  (e.g. a harder constraint, a different data structure) rather than repeating
  identically.
